# Флорбол Тренер для GitHub Pages

Це готова статична вебверсія застосунку. Вона адаптується до екрана iPhone, відкривається у Safari та може бути додана на початковий екран як вебзастосунок. Сервер або платний хостинг не потрібні.

## Опублікувати через GitHub Pages

1. Створи новий публічний репозиторій на GitHub, наприклад `florball-coach`.
2. Розпакуй ZIP і завантаж **усі файли й папку `assets`** у корінь репозиторію. Файл `index.html` має лежати саме в корені.
3. На сторінці репозиторію відкрий **Settings → Pages**.
4. У розділі **Build and deployment** вибери **Deploy from a branch**, гілку `main` і папку `/ (root)`, потім натисни **Save**.
5. Після публікації GitHub покаже адресу на кшталт `https://твоє-ім'я.github.io/florball-coach/`. Надішли це посилання друзям.

## Додати на iPhone

Відкрий посилання у Safari, натисни кнопку **Поділитися**, вибери **На початковий екран** і підтверди додавання. Після першого відкриття застосунок кешує файли й може завантажуватися офлайн.

## Можливості

- локальний профіль гравця;
- флорбольні нормативи: додавання, редагування, видалення та запис виконань;
- план тренувань за днями тижня;
- три готові комплекси з покроковими таймерами;
- статистика, графік за 7 днів, особисті рекорди та серія тренувань;
- щоденні нагадування, поки вебзастосунок відкритий;
- експорт та імпорт резервної копії JSON;
- встановлення як PWA та базова офлайн-підтримка.

## Дані та нагадування

Профіль, нормативи й результати зберігаються тільки в локальному сховищі браузера. Кожен друг, який відкриє посилання, матиме власні окремі дані. Онлайн-акаунтів і синхронізації між телефонами немає. Не очищай дані Safari, якщо хочеш зберегти записи; для перенесення скористайся резервною копією в профілі.

Браузер перевіряє нагадування, коли сторінка або встановлений вебзастосунок активні. Надійні сповіщення, коли застосунок повністю закритий, потребують серверної push-служби, якої в цій статичній версії немає.
